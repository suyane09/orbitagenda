# Orbit Agenda — Comissões, etapa 1
- Regra por profissional: sem comissão, percentual ou valor fixo.
- Cálculo puro sobre o valor efetivamente recebido, proporcional para pagamentos parciais.
- Estornos reduzem o valor líquido e podem gerar ajuste negativo.
- Não registra pagamentos a profissionais nem altera o Financeiro atual.
- SQL é proposta para revisão; NÃO aplicado no Supabase.
- Próxima etapa: ledger imutável de comissão, snapshots da regra por atendimento,
  ajustes por estorno, repasses e interface de configuração. Não calcular repasses
  apenas com a regra atual, pois ela pode mudar após um atendimento.
